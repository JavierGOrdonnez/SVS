# SPEC-mortality.md — mortality module

Part of the SVS spec. Top-level goal/shared constraints/invariants/roadmap/bug
log live in [`SPEC.md`](../../SPEC.md); this file owns §T tasks T2, T7, T49
and this module's domain-specific §I content only (no domain-specific §V
invariant was carved out for mortality — it relies entirely on the shared
invariants in top-level `SPEC.md`).

Note: the population denominator (`population_spain_midyear_5yr.csv`, T6)
that this module's rate computations join against is generated by
`src/analysis/parse_ine_population.py` — see [`SPEC-analysis.md`](../analysis/SPEC-analysis.md),
since it's a shared denominator feeding every domain, not mortality-specific.

## §I — Interfaces (mortality-specific)

```
file: data/processed/mortality_spain_ine_ecm.csv       → all-cause mortality by age × sex × cause 2000-2024 from INE ECM table 7947 (198k rows) (T49)
file: data/processed/mortality_by_chapter.csv, mortality_by_age_sex.csv, mortality_key_causes.csv → mortality summary CSVs (T49)
file: data/processed/mortality_rates.csv               → age-specific annual incidence rates per 100k (198k rows, full deaths × pop join) (T7)
file: data/processed/mortality_rates_key.csv, mortality_rates_all_cause_by_age.csv → mortality rate subsets (key causes; concise all-cause-by-age) (T7)
cmd:  `uv run python src/mortality/parse_ine_mortality.py`        → INE API table 7947 JSON dump → `mortality_spain_ine_ecm.csv` (T49)
cmd:  `uv run python src/mortality/summarize_mortality.py`        → `mortality_spain_ine_ecm.csv` → summary CSVs (T49)
cmd:  `uv run python src/mortality/compute_mortality_rates.py`    → `mortality_spain_ine_ecm.csv` + `population_spain_midyear_5yr.csv` → rate CSVs (T7)
file: `src/mortality/build_dashboard_data.py`           → `build()` reads the rate/summary/ECM CSVs, consumed by `src/analysis/build_dashboard.py` → `docs/data/mortality.json`; legacy stdout-JS `main()` kept for standalone use (T17,T23)
doc:  `data/sources/ine_causas_muerte.md`               → INE ECM table 7947 source doc (T49)
```
