## §I — Interfaces (migration-specific)

```
file: data/raw/migration_spain.csv                     → migration flows & stock 2000-2025: by sex, age, origin nationality, foreign/Spanish split (T11, 2337 rows; merged from claude/spain-migration-data-PsIYr 2026-06-07); joint age(5yr)×sex×citizenship cross for top-50 nationalities (flow 1998-2024, stock 2002-2025) added via `src/migration/parse_eurostat_migration_cohort.py` from Eurostat SDMX-JSON API `migr_imm1ctz`/`migr_pop1ctz` — series `stock_nationality` (renamed from `stock_foreign_nationality`, per-country, includes ES for feminicide denominator); `flow_immigration_from_abroad` (per-country); ~86% coverage of INE ECP total foreign stock (V42, B34); also carries `Y_LT15`/`Y_GE65`/`Y_GE85` aggregate age bands (age_group `0-14`/`65+`/`85+`) plus fine 5yr bands through `80-84` for the T69/T70 age pyramids — the `60-64`...`80-84`/`Y_GE85` bands required a live Eurostat API pull (`data/raw/eurostat_migr_pop1ctz_es.jsonl` originally only carried bands through 55-59)
file: data/sources/migracion_espana.md                 → migration source doc — INE EMCR/EVR/Padrón/ECP, Eurostat, MISSM table refs + caveats (2008, 2021 method breaks)
cmd:  `uv run python src/migration/parse_eurostat_migration_cohort.py <flow.jsonl> <stock.jsonl>` → Eurostat SDMX-JSON API `migr_imm1ctz`/`migr_pop1ctz` (pre-downloaded JSONL, not bulk TSV) → appends to `migration_spain.csv` (T11,T43,T44,T66)
file: `src/migration/build_dashboard_data.py` (formerly `build_migration_dashboard_data.py`) → `build()` reads `migration_spain.csv`, consumed by `src/analysis/build_dashboard.py` → `docs/data/migration.json` (T-mig-tab)
```

## §V — Invariants (migration-specific)

V25: recent-arrival-cohort population (no direct tenure-stratified table exists) ! approximated as cumulative net migration inflow over the trailing ~3yr window, joined against `migration_spain.csv` (T11) age-band × sex × origin-nationality data (closest available band to 15-59 male); settled_pop = stock − cohort_pop; ⊥ presented without documenting the approximation + its caveats (naturalization, re-emigration, irregular-migration undercount all bias in either direction). UPDATE 2026-07-01: for Morocco (MA) and Algeria (DZ) specifically, `migration_spain.csv` now carries the *real* joint 5yr-age-band × sex × citizenship cross (flow 1998-2024, stock 2002-2025, via Eurostat `migr_imm1ctz`/`migr_pop1ctz` — INE's own tables 24290/36825 only reach 2021/2022) — no extrapolation needed for T41's cohort_pop/settled_pop split for these two countries; the cumulative-inflow approximation above still applies wherever this direct cross is absent (other nationalities in T42's broader correlation scope). UPDATE 2026-07-20: expanded to top-49 nationalities (T43,T44,T66); `stock_nationality` series now carries per-year per-nationality sex-specific stock for ~86% of INE ECP foreign stock (V42). UPDATE 2026-07-22: re-running `parse_eurostat_migration_cohort.py` (T69) against the already-downloaded JSONL picked up Romania (RO), which had full Eurostat coverage but had been missing from `migration_spain.csv` since a stale regeneration — count is now 50 nationalities, not 49; AT remains absent (never downloaded). UPDATE 2026-07-23: T69/T70 pyramids extended to a 16-band scale (0-9...75-79, 80+) — the `60-64`/`65-69`/`70-74`/`75-79`/`80-84`/`Y_GE85` Eurostat age bands were not in the originally pre-downloaded JSONL (only through 55-59 + the `Y_GE65` aggregate) despite being available live from `migr_pop1ctz`; live-fetched for all 50 nationalities and appended to `data/raw/eurostat_migr_pop1ctz_es.jsonl`.
