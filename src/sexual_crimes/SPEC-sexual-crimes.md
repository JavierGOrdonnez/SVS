## §I — Interfaces (sexual_crimes-specific)

```
file: data/raw/sexual_crimes_mir_{year-range}.json    → Informe series (2019-2024) sexual violence extracts from MIR, nested Pydantic-validated schema (categories×sex + nationality×sex per report, no repeated totals per row); generated by T21/T22 (replaces flat CSV — see B8/V19)
file: data/raw/sexual_crimes_mir_anuario_2016-2023.json → Anuario Estadístico series (2016-2023, single file; independently sourced, cross-validated against the Informe series per B23) sexual crimes chapter, same nested schema; generated by T21's `AnuarioParser` (`--mode anuario`); kept in a separately-tagged file rather than merged into the Informe file, since the two are distinct publications (see B23)
file: data/raw/sexual_crimes_mir_balance_2019-2025.json → Balance de Criminalidad quarterly series (2019-2025; 2016-2018 excluded, older PDF table layout not supported by current parser, see B26; independently sourced, cross-validated against the Anuario series per B24) sexual crimes NACIONAL-table total + con-penetración subcategory only (coarser than Anuario/Informe — only 2 subcategories exist in this table); one `MIRReport` per year built from that year's Q4 ("enero a diciembre") cumulative figures, NOT a sum of the 4 quarters (each quarterly PDF is cumulative year-to-date, not incremental — see B24); generated by T55's `BalanceParser`/`run_balance_batch` (`--mode balance`)
file: data/processed/sexual_crime_evolution.csv        → category + nationality trend series feeding `plot_sexual_crime_trends.py`'s standalone reports/figures (T42); no longer read by `build_dashboard_data.py` (T74 — its category section is missing 2020 entirely despite the raw Informe JSON having full 2020 category data; the dashboard now reads categories/nationality directly from the Informe JSON instead)
cmd:  `python src/parsers/mir_parser.py <pdf_dir>`               → extract MIR PDFs (Informe + Anuario) → CSV with validation (T21,T22)
cmd:  `python src/parsers/mir_parser.py --mode anuario <pdf_dir>` → Anuario Estadístico series (T21)
cmd:  `python src/parsers/mir_parser.py --mode balance --pdf-dir <dir> [--out-dir <dir>]` → parse Balance de Criminalidad quarterly PDFs' NACIONAL sexual-crimes rows → one `MIRReport`/year from that year's Q4 (annual) figures, NOT summed quarters (T55, see B24)
cmd:  `uv run python src/sexual_crimes/plot_sexual_crime_trends.py` → category & nationality trend analysis + `sexual_crime_evolution.csv` + 3 charts (T42)
file: `src/sexual_crimes/build_dashboard_data.py`       → `build()` reads all 3 MIR JSON files directly (Informe for categories/nationality/clearance-rate, Anuario to backfill 2016-2018 totals, Balance for a 2025 provisional total + independent cross-check overlay) + the convictions CSV, consumed by `src/analysis/build_dashboard.py` → `docs/data/sexual_crimes.json` (T3,T21,T22,T73,T74,T75)
doc:  `data/sources/mir_informes_delitos_sexuales.md`   → MIR sexual-crimes source doc (Informe/Anuario/Balance provenance, discrepancies B6/B23/B24/B26/B38)
```
