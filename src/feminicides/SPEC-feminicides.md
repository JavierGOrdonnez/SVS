## §I — Interfaces (feminicides-specific)

```
file: data/raw/feminicidios_delegacion_{min_year}-{max_year}.json → feminicide reports 2003-2026, one Pydantic-validated report per year (regional/age/origin/relationship/cohabitation breakdowns; report-level source_page/confidence/verified, not per-category — V20); 2003-2005 legacy-format years carry low-confidence stub reports only (see notes field), real 2003-2005 figures still live in `violence_spain.csv` via T1's manual entries (generated by T19/T20)
file: data/processed/feminicide_rates_2024.csv          → per-origin (Spanish/foreign) feminicide rate per 100k with 95% CIs (generated by T24)
cmd:  `python src/parsers/feminicide_parser.py --pdf <pdf_path> | --pdf-dir <dir>` → parse one or all Delegación feminicide PDFs (2003-2026) → single `data/raw/feminicidios_delegacion_{min_year}-{max_year}.json` (T19,T20)
cmd:  `uv run python src/feminicides/compute_feminicide_rates.py` → per-origin population-adjusted feminicide rates (T24)
file: `src/feminicides/build_dashboard_data.py`           → `build()` reads the feminicide JSON + rates CSV, consumed by `src/analysis/build_dashboard.py` → `docs/data/feminicides.json` (T23,T24)
doc:  `data/sources/delegacion_gobierno_femicidio.md`    → manually curated feminicide figures, now sourced from the parsed JSON (see B22)
```
