# Sources Index

One-page map over the living source documents in `data/sources/`. Each entry: what it covers,
the confidence level of its key figures, and the caveats most likely to bite when joining or
comparing series. For verification workflow and spot-check values, see `../../VERIFICATION_GUIDE.md`.

**Where MIR PDFs come from:** `https://estadisticasdecriminalidad.ses.mir.es/publico/portalestadistico/publicaciones.html`
is the canonical hub for essentially all Ministerio del Interior crime-statistics publications —
Anuario Estadístico, Informe sobre Delitos contra la Libertad e Indemnidad Sexual, Balance de
Criminalidad (quarterly), and Informes de Delitos de Odio all live there. `data/sources/` sorts
PDFs from each family into its own subfolder — `anuario-estadistico/`, `informes-delitos-sexuales/`,
`balance-criminalidad/`, `odio/{informes-mir,encuesta,plan-accion}/`, `feminicidios/`, `reference/`
(unparsed/methodology-only PDFs) — while every `.md` source doc below stays flat directly under
`data/sources/`. Anuario, Informe-sexual-crimes, Balance de Criminalidad, and Informe de Delitos de
Odio all now have a parser + dedicated doc below (T21/T55/T59).

## Quick orientation by question

- **"Where do sexual-violence crime counts come from?"** → `mir_informes_delitos_sexuales.md` (police-recorded) + `fiscalia_memorias.md` (proceedings) + `ine_poblacion_femicidios.md` (convictions, incl. nationality table 28716)
- **"Where's the femicide/homicide data?"** → `delegacion_gobierno_femicidio.md` (partner/ex-partner registry) + `homicidio_espana.md` (all-cause by sex) + `cgpj_violencia_genero.md` (judicial cross-check)
- **"Where's the migrant population denominator?"** → `migracion_espana.md` (flows + stock by nationality/origin/age/sex) + `ine_poblacion_femicidios.md` §1 (Padrón table 31304)
- **"Where's the Spanish-national population denominator?"** → `ine_poblacion_femicidios.md` §1b (INE table 56936, direct nationality split — `population_spain_nationality.csv`, 2002+ only, V46/B44)
- **"Where's the survey/dark-figure data (vs. police reports)?"** → `macroencuesta.md` + `fuentes_secundarias_analisis_espana.md`
- **"Where do mortality-rate denominators come from?"** → `ine_poblacion_estimaciones.md` (population) + `ine_causas_muerte.md` (deaths by cause)
- **"Where's the migration→hate-speech→aggression pipeline documented?"** → `discurso_odio_inmigracion_espana.md` (official tracking, civil-society monitors, case studies El Ejido/Torre Pacheco)
- **"Where's the official hate-crime data by category (racism, antisemitism, disability, etc.)?"** → `mir_delitos_odio.md` (MIR Informe de Delitos de Odio, 2016-2021+2023 parsed; nationality by category 2021-2024 from the SES portal)
- **"What's the nationality breakdown of hate-crime victims/aggressors, and is LGTBI-phobia driven by immigration?"** → `mir_delitos_odio.md` (all-ámbitos, 2021-2024) + `lgtbifobia_espana.md` (OSIG-specific, 2021-2024 — majority Spanish on both sides, corroborated across 3 independent data sources)
- **"How does Spain compare to other EU countries on gender-based violence?"** → `eige_fra_comparative.md` (EIGE/FRA/Eurostat access mechanisms + comparability caveats — read the caveats before citing any cross-country number)
